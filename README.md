# Лабораторная работа №25. Изучение системы контроля версий Git

Учебный проект по дисциплине «Технология разработки программного обеспечения».

**Выполнил:** учащийся 3 курса группы ПО-2409 Кеда Арсений  
**Преподаватель:** Игнатович К.В.

## Содержимое проекта

* `index.html` — главная страница проекта;
* `style.css` — файл стилей, подключённый к странице.

## Использованные возможности Git

* инициализация локального репозитория и настройка окружения;
* индексация файлов и фиксация коммитов;
* параллельные ветки `feature-styles` и `feature-hotfix`;
* слияние по стратегии Fast-Forward;
* разрешение конфликта слияния с ручным аудитом маркеров;
* синхронизация с удалённым репозиторием GitHub (`push`, `pull`).
